## Setup KiCad
The first step in developing our board is to install and configure all the necessary design software.
In this tutorial, we'll use KiCad: the most popular and widely used software for developing schematics and PCBs.
KiCad is obviously free and open source.

## Download and Install KiCad
![KiCad website](/kicadWebpage.png)
You can download KiCad from the official website: [https://www.kicad.org/download/](https://www.kicad.org/download/).
Choose the appropriate version for your operating system and your and your geographic area of reference.
Once downloaded, run the installer and follow the instructions to complete the installation.
We recommend installing all components, although this may require several gigabytes of space.

When you launch KiCad, you will see the main page where you can create a new project or open an existing one.
Before we start creating our project, we will explain some of the main tools and features of KiCad that we will use in this tutorial.

## KiCad Tools and Features
![KiCad main page](/kicadMainPage.png)

- **Schematic Editor**: This is the tool where we will create the schematic of our board. It allows us to place components, connect them with wires, and define the electrical connections between them.
- **Symbol Editor**: This is a collection of symbols that represent the components we will use in our schematic. We can search for the components we need and place them in our schematic.
- **PCB Editor**: This is the tool where we will design the layout of our PCB. It allows us to place the components on the board, route the traces, and define the physical layout of our design.
- **Footprint Editor**: This is a collection of footprints that represent the physical layout of the components on the PCB. We can search for the footprints we need and place them in our PCB layout.
- **Gerber Viewer**: This is a tool that allows us to view the Gerber files generated from our PCB design. Gerber files are the standard format for manufacturing PCBs, and this tool allows us to verify that our design is correct before sending it to production.
- **Image Converter**: This is a tool that allows us to convert images into footprints or symbols. This can be useful if we want to create custom components or graphics that are not available in the standard libraries.
- **Calculator Tools**: KiCad also includes various calculator tools that can help us with tasks such as calculating trace widths, impedance, and other electrical parameters.
- **Drawing Sheet Editor**: This is a tool that allows us to create custom drawing sheets for our schematics and PCB layouts. We can define the size, title block, and other elements of our drawing sheets to suit our needs.
- **Plugin and Content Manager**: This is a tool that allows us to manage plugins and content libraries for KiCad. We can install additional libraries, symbols, and footprints to expand the capabilities of KiCad and customize it to our needs.

## Getting Started
Now that we have KiCad installed and we are familiar with its main tools and features, we can start creating our project.
To create a new project, click on "File" in the top menu and select "New Project". Choose a name and location for your project and click "Save".
This will create a new project folder with the necessary files and directories for your design.

The files that make up a new project are:
- project_name.kicad_pro: This is the main project file that contains information about the project and its settings.
- project_name.kicad_sch: This is the schematic file where we will create our schematic design.
- project_name.kicad_pcb: This is the PCB layout file where we will design the physical layout of our board.
