# Redboard
Design an RP2040-powered board, get funds to build it!

## What is Readboard
Redboard is a YSWS where students design a custom RP2040-powered PCB from scratch, earn credits based on tracked hours, and redeem them for grants to manufacture and build their board.

## How does it works
For each project there will be two phases: 
- The design phase, where participants design any RP2040-powered board, develop the PCB and track their time spent on KiCad with Lapse. After shipping the project, they will receive 1 credit per hour tracked. 
- The build phase, where participants spend their credits in the shop to get: a PCB manufacturing grant; a components grant; optional tools (soldering iron, multimeter, etc.). Then they physically build the board, tracking the build time with Lapse and earning additional credits.

## What a shipped project will have
A shipped Phase 1 project includes:
- Public GitHub repo with all the source files
- Handwritten README and JOURNEY files
- Photos of the board design

A shipped Phase 2 project includes:
- A short video of the board working
- Photos of the assembled board
